# حكاية — Arabic through stories

A static Arabic reading website: a library of short illustrated stories with versions A/B/C, sentence-by-sentence English translation on request, tap-a-word meanings, comprehension questions with feedback, word flashcards, a read-aloud step, a private writing prompt, an audio player for recordings, related stories and a link for every story (`#story-<slug>`). Progress and drafts are saved on the reader's device only.

The library is empty until approved stories are published. A sample story for testing the reader opens at `/?preview=where-is-the-phone`.

## Run locally

No dependencies or build step. From the repository root:

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. Pages load stories as JSON, so open them through a server, not as files.

## Files

- `dist/index.html`, `dist/style.css`: page layout, illustrations and styles.
- `dist/app.js`: renders the library, the word section and the reader from the story files.
- `dist/content/config.json`: level labels, topics, collections, answer-checking rules.
- `dist/content/stories/*.json`: one file per story ([format](docs/story-format.md)).
- `dist/content/index.json`: the published-story list, generated by the validator. Don't edit by hand.
- `scripts/validate.mjs`: checks every story file and rebuilds the index.
- `tests/e2e.mjs`: browser checks (Playwright + Chromium).
- `docs/`: [language guidelines](docs/language-guidelines.md), [Narrative Quality Standards](docs/narrative-quality-standards.md), [story format and publishing](docs/story-format.md).
- `.openai/hosting.json`: existing Sites project identity and static output directory.

## Adding a story

See [docs/story-format.md](docs/story-format.md): write to the guidelines and NQS, fill in a story file, run `node scripts/validate.mjs`, preview at `/?preview=<slug>`, then publish.

## Audio

A story's own recording plays when the story file has one (`readings[].audio.src`). Otherwise the reader falls back to the browser's Arabic speech synthesis and labels it as an automatic reading. Do not place API keys in browser code or commit credentials.

## Hosting

The original site is hosted at https://hikaya-arabic-stories-nov8.grittycedar3.chatgpt.site. GitHub pushes are not automatically synchronized with Sites. Serve `dist/` when deploying to another static host, and run the validator first.
