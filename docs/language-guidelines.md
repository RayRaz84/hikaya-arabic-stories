# Language and content guidelines

These govern Arabic variety, learner levels, story construction, vocabulary, grammar, diacritics, translations and activity language. They are authored by the project team and apply to **content**, not to the website code. This is the short version supplied at project start; replace it with the full document when available.

## Nature of the language

* Simplified, spoken-style MSA — comprehensible fusha, not literary, not dialect
* Spoken-leaning forms where they're high-frequency: عنده for possession, هناك for "there is"
* **Decided:** negated possession uses ليس عنده (e.g. ليس عنده الهاتف)
* Short one-clause sentences; connectors limited to لكن، لأن، الآن، جدًا، ثم
* **Decided:** all Arabic text is fully vowelled: stories, activity items, word banks and teacher notes
* Strategic English allowed for the teacher; never for stories or assessment

## Vocabulary

* Every word justified by rank in the Buckwalter–Parkinson frequency dictionary; targets from the top 100 where possible
* Max 3 target structures and 10–15 lexical items per lesson; support words capped at 8–12
* High-frequency only; cognates welcome; descriptive/low-frequency words (suddenly, delicious, grilled chicken) banned at novice level
* **Decided:** recycling previously introduced words is recommended when the repetition is meaningful (humor, anticipation, a real pattern); otherwise drop it rather than add sentences only to repeat. Mastery = 70–150 encounters, tracked in a spreadsheet

## Vocabulary presentation

* Guiding-words page: Arabic + 1–3-word English gloss + fixed image cue (transliteration optional, never in stories)
* Meaning established visually and by gesture before any text; "point, don't memorize"
* Circling: 5–8 questions per sentence (yes/no, either/or, wh-, personalized)
* PQA: same question to 3–5 students, mining funny answers
* No grammar explanation, no conjugation charts, no translation drills

## Story construction

* Recurring character: Khalid
* **Decided:** no fixed structure and no set number of failed attempts. Want → problem → attempts → resolution is one option among others (discovery, humor, friendship, misunderstanding, a shared experience)
* Three embedded versions: Story A 40–60 words, Story B 80–120, Story C 150–220; length and emotion grow, grammar doesn't
* Funny or absurd where it fits; few characters, no dense description
* Every story must also meet the Narrative Quality Standards (NQS 1.0), see narrative-quality-standards.md

## Reading framework

* Oral input first, no text → interaction → PQA → micro reading (Reading A) → expansion (Reading B) → mini story → exit check
* Teacher reads aloud first; readings are image-supported and embedded (each layer re-reads the last)
* Progression across weeks: command cards → illustrated dialogue → personalized class story → mini-book → co-created story → expanded familiar stories

## Activities and assessment

* Fixed menu: match meaning, listen and choose, sequencing, draw the sentence, true/false (صح/خطأ), find someone who, retell, picture talk
* Items in Arabic reusing story sentences; instructions in English; single-word Arabic answers accepted
* Assessment is comprehension-only: match, read-and-choose, true/false, simple questions; 70% comprehension / 30% form
